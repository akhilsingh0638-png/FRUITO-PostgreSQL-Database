# FRUITO — E-Commerce PostgreSQL Database Project

A portfolio-ready PostgreSQL database project for a fresh grocery e-commerce business.

## Main areas
- Customers and addresses
- Categories and products
- Inventory
- Coupons
- Orders and order items
- Payments
- Reviews
- Views, transactions and analytics
- Indexing and EXPLAIN ANALYZE

## Run order
1. 01_schema.sql
2. 02_seed.sql
3. 03_queries.sql
4. 04_views.sql
5. 05_transactions.sql
6. 06_analytics.sql
7. 07_indexes_and_explain.sql

`08_interview_questions.md` is for interview preparation and is not a SQL script.
